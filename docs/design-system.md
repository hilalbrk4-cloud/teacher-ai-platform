# EduPilot Design System

## Design Direction

EduPilot is a premium AI workspace for teachers.

The interface should be calm, minimal, modern, professional, spacious without feeling empty, and interactive without feeling busy.

Use the current Dashboard v1 as the visual foundation.

## Primary Visual Reference

`/references/smart-dashboard.png`

Use it to understand spacing, layout proportions, card hierarchy, navigation structure, and visual balance. Do not copy branding, text, or product identity.

## Color Direction

Prefer white surfaces, soft neutral backgrounds, dark slate or navy navigation, restrained indigo accents, accessible text contrast, and subtle status colors.

Avoid pure black for large surfaces, excessive purple, large saturated gradients, childish rainbow palettes, and too many accent colors.

## Typography

Use a clear hierarchy for page titles, section titles, body text, helper text, and buttons. Keep font sizes, weights, and line heights consistent.

## Spacing

Use predictable padding, balanced vertical rhythm, aligned section edges, no arbitrary margins, and no excessive empty gaps.

## Cards

Use consistent radius, subtle borders, soft shadows where needed, clear hierarchy, restrained hover elevation, and consistent padding.

## Buttons

Support primary, secondary, and tertiary actions. Include hover, focus, disabled, and loading states when relevant.

## Icons

Use Lucide icons unless the project already defines another consistent system.

## Motion

Use short hover transitions, gentle card elevation, smooth state changes, and clear loading feedback. Avoid distracting motion.

## Responsive Design

Desktop, tablet, and mobile must all be usable. Preserve primary actions, stack panels logically, avoid horizontal overflow, and keep form controls readable.
